# ucarpha — відмовостійкість FreePBX 17 на CARP

[English](README.md) · **Українська**

Завантаження **ucarpha** — модуля FreePBX 17, який тримає плаваючу віртуальну IP-адресу між двома станціями через
[ucarp](https://github.com/jedisct1/UCarp), перевіряє здоров'я Asterisk і сам перемикає при відмові.

**Завантажити:** [остання версія](../../releases/latest) — `ucarpha-<версія>.tgz` (архів для Module Admin) і необов'язковий `.deb`.
Контрольні суми — у `SHA256SUMS`.

> **Статус: експериментальний.** Перевірено на тестовій парі FreePBX 17.0.33 (Debian 12). Модуль непідписаний і має
> root-помічників, що керують мережевими адресами та сервісами. Спершу випробуйте на тестовій парі, не на робочій станції.

## Що він робить
Телефони й транки працюють з однією **віртуальною IP (VIP)**. Рівно один вузол — MASTER — тримає її. Якщо MASTER стає
нездоровим, VIP переходить на інший вузол, і дзвінки працюють далі без жодного переналаштування.

- **Перевірки здоров'я** на кожному вузлі: процес Asterisk, CLI Asterisk, SIP (OPTIONS по UDP) і MariaDB.
- **Спершу самолікування:** нездоровий MASTER перезапускає Asterisk (друга спроба — жорстке завершення й запуск). Лише
  якщо не допомогло, віддає VIP peer-у — і тільки якщо peer відповідає на SIP, тож VIP ніколи не потрапить на мертвий вузол.
- **Хворий резервний вузол не може перехопити VIP:** він виходить із голосування CARP і повертається після кількох
  здорових перевірок.
- **CARP Maintenance у стилі pfSense:** *Enter / Leave Persistent CARP Maintenance Mode* (зберігається після перезавантаження)
  і *Temporarily Disable CARP / Enable CARP* (до ввімкнення назад або до перезавантаження) — для планових робіт на вузлі.
- **Розклад:** віддати VIP у день/час і забрати пізніше (наприклад, вівторок 05:00 → середа 05:00).
- **Сповіщення:** syslog і e-mail; живий JSON зі станом для Zabbix.
- **Сторінка з покроковим налаштуванням і Help:** підказує, чого ще бракує (ucarp, root-помічники, адреси у фаєрволі) і
  як усе видалити. Нічого не встановлюється і не змінюється від root автоматично.

Конфігурація між вузлами **не синхронізується** (розширення, транки тощо потрібно тримати однаковими самостійно).

## Встановлення (на кожному вузлі)
1. Завантажте `ucarpha-<версія>.tgz` і додайте через **Admin → Module Admin → Upload**, потім встановіть.
   Модуль непідписаний: якщо його відхилено, від root виконайте `fwconsole setting SIGNATURECHECK 0`.
2. Відкрийте **Admin → CARP High Availability**. Сторінка покаже кроки, яких бракує, і дасть посилання на фаєрвол:
   - `apt-get install ucarp` (від root);
   - один раз від root: `sh /var/www/html/admin/modules/ucarpha/bin/setup-root.sh` (повторюйте після кожного оновлення модуля);
   - додайте цей вузол, інший вузол і VIP до зони *Trusted* фаєрвола.
3. Вкажіть VIP, IP цього вузла, IP peer-а, VHID, пароль і роль, збережіть. На другому вузлі — протилежна роль і ті самі
   VIP, VHID та пароль.

## Вимоги
FreePBX 17 на Debian, два вузли в одному L2-сегменті (CARP використовує IP-протокол 112), пакет `ucarp`.
